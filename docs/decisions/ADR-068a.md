# ADR-068a — Amendment to ADR-068: assignment `score` and `grade` are stored (migration 0021); `description`, `entered_*` and attachments stay excluded

**Status:** Locked

**Amendment to ADR-068 (2026-09-16, Checkpoint 10.2, owner-approved): the "fresh, explicit owner decision" that ADR-068 §3 reserved before any grade column could be added has been made, for two columns and no more.** `canvas_assignments` gains nullable `score` (`real`, Canvas `submission.score` — the raw points awarded, on the same scale as `points_possible`) and nullable `grade` (`text`, Canvas `submission.grade` — the display grade, e.g. `A`, `95`, `95%`, `complete`), by the strictly additive migration `0021_canvas_assignment_grades` (level **22**). Both are provider strings/numbers in the sense of `text-bounds.ts`: bounded at write, never rejected, because the owner did not author them. **Percentage is not a column**: it is derived at read time from `score / points_possible` so the two can never disagree, and only when both are present and `points_possible > 0`. The decision was taken with ADR-068's own FERPA reasoning in front of the owner — the amendment records that the owner chose to hold a grade at rest for the Academic Intelligence Layer, not that the reasoning was wrong. **Everything else ADR-068 §3 excluded stays excluded, on the same terms:** assignment `description` (unbounded instructor-authored HTML with no in-app renderer — `html_url` remains the one-tap link to the full prompt), `entered_score`/`entered_grade` (the pre-late-policy values, a second near-duplicate grade with no Personal OS consumer), and submission `attachments` (the student's own uploaded work, a higher sensitivity tier than a number). Each remains structurally inexpressible on the wire (`CanvasAssignmentSchema` and every `Academic*` schema are `.strict()` and their tests walk the key sets) and unread in translation (`packages/canvas-providers/src/translate.ts` never reads them). **A grade is never logged, never searched, and never reaches a model call**: the worker's `canvas.sync.*` lines stay counts-only, `GET /search` does not join the Canvas tables (ADR-065's privacy-argument rule for any new entity), and Checkpoint 10.2's "no AI processing of academic data" rule is enforced by construction (ADR-070) rather than by policy. ADR-068's other clauses — PAT authentication, per-course polling, the mail/health idempotency and failure-containment template, no mutations, no new egress surface — are unchanged (Checkpoint 10.2, 2026-09-16)
